# Happle

## Language: Haskell

## About

Usage of various packages:

* Database (postgresql) connection and querying (**hasql**)
* Configuration loading into environment (**dotenv**)
    - see: .example-env
* Logging (**hslogger**)
* Formatting with string interpolation (**fmt**)

## Usage

Build and run from the command line:
```
$ cabal build
$ cabal run
```
